## Project Overview

This project focuses on analyzing sales, customer, employee, product, order, and payment data using Microsoft Power BI.

The project combines multiple datasets from the Classic Models database to create an interactive sales and performance dashboard.

## Dashboard Pages

### 1. Executive Sales & Performance Overview

Provides an overall view of sales and business performance using KPI cards, charts, a treemap, and interactive slicers.

### 2. Customer & Sales Force Deep-Dive

Focuses on customer and employee performance, including sales analysis, top-performing employees, and customer-related insights.

### 3. Annual Sales Cohort Comparison

Provides a comparison of annual sales performance using visual analysis and supporting metrics.

## Project Workflow

### 1. Data Preparation

- Imported multiple CSV datasets into Power BI.
- Prepared and transformed the data for analysis.
- Built a connected data model using the available business datasets.

### 2. Data Analysis

- Created measures for sales, profit, customers, orders, and performance.
- Analyzed product, customer, employee, and yearly sales performance.
- Used DAX measures to support business analysis.

### 3. Dashboard Development

- Created Power BI dashboard pages.
- Added KPI cards, slicers, charts, tables, scatter plots, and treemaps.
- Designed interactive views for exploring sales and performance data.
